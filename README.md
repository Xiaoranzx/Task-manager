# Task Manager Automation Test

## 📌 Description
โปรเจกต์ Automation Test ด้วย Playwright สำหรับระบบ Task Manager

แนวคิด วิธี
test case แบบละเอียดตามทุกขั้นตอน หรือตารางที่มี Expect result ยังไม่ได้ทำขึ้นมาจริงๆค่ะ แต่โดยปกติแล้วทำไว้นะคะ ซึ่งเขียนออกมาคล้ายกันค่ะ จะมีเคส valid และ invalid
ตอนนี้ใช้วิธี ออกแบบเป็น Scenario เพื่อมองภาพให้ชัดขึ้นค่ะ

## How to run test 
ติดตั้ง Extention Playwright Test for VSCode จะมีไอคอน แก้วแลบวิทยาศาสตร์ขึ้นมา 
สามารถเลือกไฟล์ run ได้เลยค่ะ จะแสดง หน้าเว็บให้เราดูด้วยว่าทำงานอย่างไรบ้าง

หรือ 
npx playwright test
report จะออกเป็น html ค่ะ
